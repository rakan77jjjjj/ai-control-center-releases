# AI Control Center — الإصدارات الرسمية

هذا المستودع للإصدارات فقط: ملف التثبيت وقائمة التحديثات. الكود المصدري خاص.

- **تثبيت أول مرة:** نزّل أحدث `AI-Control-Center-x.y.z-Setup.exe` من [Releases](../../releases/latest).
- **التحديث:** البرنامج يتحقق من التحديثات بنفسه (إذا سمحت بالتحديثات في صفحة الشبكة)، ويثبّت النسخة الجديدة بعد موافقتك.
- **الأمان:**
  - كل ملف تثبيت موقّع رقميًا من «AI Control Center Updates».
  - البرنامج يرفض أي ملف ما يطابق بصمته (SHA-256) أو توقيعه.
  - بياناتك محفوظة في مجلد منفصل، وما يلمسها التحديث.

# AI Control Center — official releases

This repository holds releases only: the installer and the update list. The source code is private.

- **First install:** download the latest `AI-Control-Center-x.y.z-Setup.exe` from [Releases](../../releases/latest).
- **Updates:** the app checks for updates by itself, once you allow updates on its Network page. It installs a new version after you approve it.
- **Safety:**
  - Every installer is digitally signed by "AI Control Center Updates".
  - The app refuses any file whose SHA-256 fingerprint or signature does not match.
  - Your data lives in a separate folder, and updates never touch it.
