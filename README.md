**الحالة الحالية: بوابة الوصول قيد الإعداد.**

ستُتاح تجربة تنزيل منظّمة بعد تفعيل التحقق الآمن من مفتاح الوصول. لا توجد حاليًا خانة مفتاح مفعّلة على هذه الصفحة، ولا ينبغي إرسال كلمات المرور أو مفاتيح الترخيص عبر تعليقات GitHub.

| الخدمة | الحالة |
| --- | --- |
| صفحة التنزيل المحمية | قيد التجهيز |
| التحقق من مفتاح التنزيل | غير مفعّل |
| طلب الوصول | بالتواصل المباشر مع مالك المشروع |

**ملاحظة:** عرض هذه الصفحة لا يفرض قيودًا على ملفات GitHub Releases العامة؛ الحماية الفعلية تتطلب تقييد الملفات نفسها والتحقق من المفتاح من جهة الخادم.
